인기 상품 입력

선택한 날짜의 상품 목록입니다. 행을 추가·수정·삭제 후 저장하면 해당 날짜 데이터가 교체됩니다.

카테고리 일별 입력

CSV 붙여넣기 (상품군,회원,카테고리,결제건) — 회원은 기존회원/신규회원
